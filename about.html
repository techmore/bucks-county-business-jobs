About this directory

A simple Phase 1 aggregator for local opportunity.

This directory maps businesses within 25 miles of Tinicum Township, Bucks County, centered on 40.4825, -75.1069. It is built for job seekers, students, career changers, and local companies that want better visibility.

Local First

The directory focuses on Tinicum Township and surrounding communities, including ZIPs such as 18947 and nearby Bucks County towns.

Phase 1 Scope

This version lists companies, categories, websites, addresses, hiring status, employee counts, onboarding notes, and map locations. It does not include accounts, job posts, or a backend.

Add a Company

Anyone can add a business or fix a listing with the "Add or Fix a Business" button, which opens a GitHub issue. Future versions can connect the same data model to scripts or moderation workflows.
